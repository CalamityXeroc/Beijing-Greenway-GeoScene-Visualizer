基于深度学习与多源空间特征的北京绿道智慧推荐系统。整合 17 条北京主要绿道（1248 km）、847 处便民设施、29,993 个深度学习功能识别节点，提供从「发现 → 评估 → 规划 → 导航」的完整决策链路。

## ✨ 功能亮点

- **智能推荐** —— 多因子加权模型（功能匹配 0.55 / 热度 0.15 / 设施 0.20 / 长度 0.10），输出 65~98 推荐度与可解释理由
- **绿道体检** —— 五维雷达图（生态自然 / 出行便捷 / 设施完备 / 人气活力 / 休闲适宜）
- **交互地图** —— GeoScene 2D/3D 双视图、高德底图、图层控制、昼夜主题、绘图测量
- **路径规划** —— 13 万条 OSM 路网内存建图（最小堆 Dijkstra，22m 交叉口合并容差）+ 转向级导航
- **可达圈分析** —— 步行 / 骑行 / 驾车 5–30 分钟等时圈（凸包）
- **空间分析** —— 多边形查询、缓冲区设施统计（`ST_DWithin`）、POI 聚类、功能区划网格、热力图
- **3D 飞行漫游** —— 管状路径 + 路径光珠 + 真实地形与实时阴影
- **AI 助手** —— DeepSeek-V3.2，按意图路由提示词 + 注入绿道功能画像上下文，支持多轮对话
- **社区运营** —— 评论（17 类敏感词库拦截）、收藏、反馈、热度指数
